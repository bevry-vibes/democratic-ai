Inworld was not on the watchlist, so its two open-license releases were never pulled. Both are Apache-2.0 and both run as streams.

- **[Voice Isolator](/models/voice-isolator/)** — 48 kHz voice isolation for noisy recordings and live audio. It returns the cleaned voice and the removed background as two aligned tracks, so the same model doubles as a denoiser and as a source separator. It carries `speech-enhancement` and `speech-separation`. The card is explicit that this is not a restoration model and not a speaker selector.
- **[SAVA](/models/sava/)** — semantic acoustic voice activity. It returns a speech probability and an end-of-turn probability for each frame of a live stream, which is the pair a turn-taking voice agent needs. It carries `voice-activity-detection`.

The confirmation gate scored Voice Isolator at 0.76 for `speech-separation` and 0.67 for `speech-enhancement`, both under the 0.8 threshold, so the tasks were recorded from the model card instead.

## The window moved

Nine records left the catalogue as the 90-day window advanced past 20 August: the Ling 3.0 base checkpoints, the LiquidAI LFM2.5 DSpark releases, and the two earlier Qwen3-ASR conversions. Their repositories still exist; only the window closed. The monthly re-check is the path back in.

Two webAI models entered the same way: **Echo-Air** and **Parakeet-Air** were touched on 18 November and so re-entered the window.
