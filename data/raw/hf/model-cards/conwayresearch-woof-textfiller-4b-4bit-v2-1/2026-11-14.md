# woof-textfiller-4B-4bit-v2.1

Generates the text to enter in a selected browser field using the user goal and page context.

## Usage

Download `mlx/` for Apple Silicon or `gguf/` for a compatible GGUF runtime. Load the selected local directory and keep its files together.

Provide the user goal, selected field, and page context to a compatible local Text filler runtime. The model returns the field value as a JSON text object.
