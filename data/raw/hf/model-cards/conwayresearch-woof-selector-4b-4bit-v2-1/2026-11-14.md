# Woof Selector 4B 4-bit v2.1

**Choose the next action. Keep browser tasks moving.**

Woof Selector is a compact, local browser-use model. Given a task, the current page context and available choices, it selects the next operation and target. Quantization-aware training adapts the model for 4-bit deployment. Woof Selector is built on Qwen3.5-4B through browser-focused post-training.

**The selector decides what to do and where; the text filler supplies what to type.**

## Single-step validation

The QAT model achieved **96.6% decision acceptance (516/534)** on fixed browser-state validation, evaluated using an LLM-as-judge. Valid alternative actions were accepted.

## Usage

Download `mlx/` for Apple Silicon or `gguf/` for a compatible GGUF runtime. Download only the variant you need and keep its files together.

Use a compatible Woof Selector harness in Underdog to provide the task, page observations and candidate choices. The harness executes the selected action, reads the updated page and asks for the next decision. The model runs locally after download.

Pair Woof Selector with one of our text fillers when an action requires generated text:

| Text Filler | Apple Silicon / MLX 4-bit | GGUF 4-bit |
|---|---|---|
| **Woof-4B textfiller** | [Download](https://huggingface.co/ConwayResearch/woof-textfiller-4B-4bit-v2.1/tree/main/mlx) | [Download](https://huggingface.co/ConwayResearch/woof-textfiller-4B-4bit-v2.1/tree/main/gguf) |
| **Woof-0.8B textfiller** | [Download](https://huggingface.co/ConwayResearch/woof-textfiller-0.8B-4bit-v2.1/tree/main/mlx) | [Download](https://huggingface.co/ConwayResearch/woof-textfiller-0.8B-4bit-v2.1/tree/main/gguf) |

Both variants use 4-bit weights. MLX uses BF16 computation; GGUF uses Q4_K_M weights with runtime-selected computation. Enable Flash Attention for the GGUF selector. Preserve the supplied configuration, tokenizer and chat template.
