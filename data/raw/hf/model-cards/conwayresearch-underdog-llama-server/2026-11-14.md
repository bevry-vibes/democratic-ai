# llama-server for Underdog

llama.cpp's `llama-server`, built unmodified by Underdog to run GGUF models such as
[Underdog Saluki 27B](https://huggingface.co/ConwayResearch/Underdog-Saluki-27B-1.0)
on Apple silicon Macs (macOS 14.0 and later). The Underdog app downloads it with the
model and checks this SHA-256 before it runs it.
